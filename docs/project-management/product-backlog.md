## Workflow

1. Backlog
2. Ready
3. In Progress
4. Review
5. Testing
6. Blocked
7. Done

## Definition of Ready

A backlog item is ready when:

- The requirement is approved.
- Acceptance criteria are clear.
- Dependencies are recorded.
- The owner is confirmed.
- The team has estimated the work.
- Required design or data inputs are available.

## Definition of Done

A backlog item is done when:

- Acceptance criteria are met.
- Code or documentation has been reviewed.
- Required tests pass.
- No unresolved critical defect affects the item.
- Security, privacy, validation, and error handling have been checked.
- Relevant documentation is updated.
- The integrated application supports the completed flow.
- The team accepts the result during Sprint review.
