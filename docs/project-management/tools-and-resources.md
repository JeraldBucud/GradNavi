## Resource controls

- Use free, educational, or low-cost tiers where practical.
- Approve paid services before purchase.
- Store keys and passwords in environment variables.
- Do not commit credentials or private test data.
- Record dependency versions.
- Limit access to approved members.
- Record data sources and review dates.
- Use synthetic data for testing.
- Maintain database export, restoration, and fallback instructions.
