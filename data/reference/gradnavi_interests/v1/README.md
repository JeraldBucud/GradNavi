# GradNavi Detailed Interest Catalogue V1

This dataset defines the first reviewed GradNavi detailed Interest catalogue for WBS 5.6.

Rules:

- 36 active Careers.
- Exactly 10 detailed Interests per Career.
- Exactly 360 CareerInterest mappings.
- Every Career receives the same total Interest weight.
- Three core Interests use relevance weight 5.
- Four strong Interests use relevance weight 4.
- Three supporting Interests use relevance weight 3.
- Total relevance weight per Career is 40.
- Interests are shared across Careers where the relationship is meaningful.
- Existing GradNavi Interest names are reused.
- Detailed Interests are GradNavi-reviewed reference data.
- O*NET RIASEC occupational-interest evidence stays separate in CareerRIASECProfile.
- Source references identify the approved occupation mappings reviewed when defining each Career mapping.
- No CareerInterest mapping enters the database until this dataset passes validation and human review.
